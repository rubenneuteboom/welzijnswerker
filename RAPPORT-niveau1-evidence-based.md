## 1. Huidige situatie Niveau 1

### Wat doet niveau 1 nu?
- **11 levensdomeinen** screenen
- **Schaal:** "Gaat goed" / "Kan beter" / "Actie nodig"
- **Vraag:** "Wie helpt waar?" (informeel/collectief/formeel)
- **Output:** Overzicht welke domeinen aandacht nodig hebben

### Doelgroep
- **Iedereen:** cliënt zelf, samen met familie, of met professional
- **Laagdrempelig:** geen intake, geen dossiervorming
- **Zelfscan:** bewustwording, eerste stap

## 2. Wetenschappelijke onderbouwing

### 2.1 De 11 levensdomeinen - Waar komen ze vandaan?

#### Basis: Zelfredzaamheidsmatrix (NJi)
**Bron:** Nederlands Jeugdinstituut (NJi), Verwey-Jonker Instituut

**Oorspronkelijke 11 domeinen (SCP, 2012):**
1. Inkomen/financiën
2. Dagbesteding (werk, opleiding, vrijwilligerswerk)
3. Huisvesting
4. Huiselijke relaties
5. Geestelijke gezondheid
6. Lichamelijke gezondheid
7. Middelengebruik
8. ADL-vaardigheden (zelfverzorging)
9. Sociaal netwerk
10. Maatschappelijke participatie
11. Justitie

**Wetenschappelijke basis:**
- SCP (Sociaal Cultureel Planbureau): "Meedoen en gelukkig zijn" (2012)
- Breed gebruikt in sociaal domein (wijkteams, Wmo, Jeugdhulp)
- Gevalideerd in Nederlandse context

**RPA aanpassing:**
✅ Zelfde 11 domeinen (herkenbaarheid, vergelijkbaarheid)  
➕ **Netwerkpositie** per domein toegevoegd (informeel/collectief/formeel)

#### Internationale vergelijking

**ICF (WHO, 2001)** - International Classification of Functioning
- Body Functions & Structures
- Activities & Participation
- Environmental Factors

**→ RPA domeinen matchen ICF categorieën**

**Outcomes Star (UK, Triangle Consulting)**
- 8-10 levensdomeinen (variërend per doelgroep)
- Visuele representatie (ster)
- Self-assessment + professional assessment

**→ RPA gebruikt vergelijkbare benadering maar met netwerkpositie**

### 2.2 Schaal: "Gaat goed / Kan beter / Actie nodig"

**Current practice:**
- 3-puntsschaal (simpel, snel, laagdrempelig)

**Evidence:**
- **Likert schalen:** Meer punten (5/7) = hogere betrouwbaarheid
- **MAAR:** Bij zelfscan > 3 punten = verwarrend voor leken
- **Trimbos aanbeveling (Suus):** 3 punten is acceptabel voor screeningsinstrument

**Best practice vergelijking:**

| Instrument | Schaal | Doelgroep |
|------------|--------|-----------|
| **Outcomes Star** | 5-punts ladder | Professional + cliënt |
| **GGZ ROM** | 5-punts Likert | Alleen professional |
| **Zelfredzaamheidsmatrix** | 5-punts | Professional invult |
| **RPA Niveau 1** | 3-punts | **Zelfstandig door cliënt** |

**Conclusie Bram (methodoloog):**
> "Voor een zelfscan is 3-punts verdedigbaar. Als we validatie willen: vergelijk met professionele 5-punts assessment (niveau 2)."

---

### 2.3 "Wie helpt waar?" - Netwerkpositie

**Innovatie RPA:**
Niet alleen SCREENING (hoe gaat het?) maar ook **POSITIONERING** (wie helpt?)

**Evidence basis:**

#### Social Support Theory (Cohen & Wills, 1985)
- Informele steun (familie, vrienden) = stress-buffer
- Formele steun zonder informeel = afhankelijkheid-risico

#### Network-based approach (Gilchrist & Kyprianou, 2011)
- "Community networks are a form of social capital"
- Collectieve voorzieningen versterken duurzaamheid

#### Meedoen en Sociale Samenhang (SCP, 2020)
- Verschuiving formeel → informeel/collectief = preventie effectief
- Maar: kwetsbare groepen hebben BEIDE nodig

**RPA toepassing:**
→ Vraag niet alleen "hoe gaat het" maar "HOE is steun georganiseerd?"  
→ Dit is **uniek** voor Nederlandse praktijk

## 3. Best Practice aanbevelingen

### 3.1 Validatie niveau 1

**Nu:** Geen gevalideerde vragenlijst, wel gebaseerd op NJi-domeinen

**Aanbevelingen Bram:**

#### Fase 1: Face validity (expert review)
- [ ] Review door Suus (Trimbos)
- [ ] Review door Karin (praktijk sociaal werk)
- [ ] Review door Jan (Wmo beleid)
- [ ] Review door Lisa (ervaringsdeskundige)

**Vraag:** "Dekken deze 11 domeinen het hele leven?"

#### Fase 2: Construct validity
- [ ] Test met 50 cliënten: niveau 1 (zelf) vs niveau 2 (met professional)
- [ ] Vergelijk scores: komt het overeen?
- [ ] Interrater betrouwbaarheid: als 2 professionals niveau 2 invullen, zelfde scores?

#### Fase 3: Predictive validity
- [ ] Na 6 maanden: zijn domeinen met "actie nodig" verbeterd?
- [ ] Zijn cliënten met veel "actie nodig" vaker doorverwezen?

---

### 3.2 Verbeteringen wizard

#### Aanbeveling 1: Toelichting per domein
**Nu:** "Financiën - Gaat goed / Kan beter / Actie nodig"

**Best practice:**
```
💰 Financiën
Denk aan: inkomen, schulden, kunnen rondkomen, rekeningen betalen

○ Gaat goed - Ik kom goed rond
○ Kan beter - Soms krap, maar het lukt
○ Actie nodig - Schulden, kan niet rondkomen
```

**Evidence:** Concrete voorbeelden verhogen begrip (Plain Language Action Network, 2011)

#### Aanbeveling 2: Optionele toelichting
**Nu:** Alleen score, geen ruimte voor context

**Best practice:**
```
Wil je iets toelichten? (optioneel)
[                                    ]
```

**Evidence:** Kwalitatieve context verrijkt data (Mixed Methods Research, Creswell 2014)

#### Aanbeveling 3: Reminder "geen oordeel"
**Nu:** Kan voelen als test

**Best practice:**
```
💡 Dit is geen test. Er zijn geen goede of foute antwoorden.
Dit is om in kaart te brengen waar je nu staat.
```

**Evidence:** Reductie sociale wenselijkheid bias (Crowne-Marlowe, 1960)

---

### 3.3 Output verbeteren

#### Nu:
- Lijst met domeinen en scores
- Wie helpt waar?

#### Best practice toevoegingen:

**A) Visuele representatie**
```
Spindiagram (radar chart) met 11 assen
→ Zoals Outcomes Star doet
→ In één oogopslag zien: waar gaat het goed/minder
```

**B) Concrete next steps**
```
Gebaseerd op jouw antwoorden:
✓ 7 domeinen gaan goed - mooi!
⚠️ 3 domeinen kunnen beter - wellicht iets mee doen?
🚨 1 domein heeft actie nodig: Financiën

Wat kan je doen?
- Praat met iemand die je vertrouwt
- Neem contact op met wijkteam [link]
- Doe de uitgebreide analyse (Niveau 2) samen met een professional
```

**C) Downloadbare PDF**
```
"Bewaar je resultaten" knop
→ Print of mail naar jezelf
→ Neem mee naar afspraak professional
```

## 4. Ethische overwegingen

### 4.1 Privacy & Data
**Nu:** Alles lokaal in browser (geen server opslag)

**Best practice:** ✅ Goed!
- Geen account nodig
- Geen persoonsgegevens verzameld
- Data blijft bij gebruiker

**Aanbeveling:**
- [ ] Privacy statement toevoegen
- [ ] Duidelijk maken: "Jouw data blijft op jouw apparaat"

### 4.2 Zelfdiagnose risico's
**Risico:** Mensen interpreteren score fout ("alles rood = ik ben hopeloos")

**Mitigatie:**
```
⚠️ Let op:
Dit is een eerste scan, geen diagnose.
Rood betekent niet "er is iets mis met jou".
Het betekent: "Op dit gebied kan ondersteuning helpen."

Twijfel je? Praat met een professional.
```

**Evidence:** Health literacy guidelines (WHO, 2013)

### 4.3 Toegankelijkheid
**Aanbeveling:**
- [ ] WCAG 2.1 AA compliance (toegankelijkheid slechtziend/blind)
- [ ] Taalniveau B1 (begrijpelijk voor iedereen)
- [ ] Beschikbaar in meertalige versie (Engels, Turks, Arabisch?)
