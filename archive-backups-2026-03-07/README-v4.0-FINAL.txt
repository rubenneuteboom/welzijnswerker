✅ WAT WERKT NU:

Bij elk domein, als je klikt op "🟡 Steun aanwezig":

1️⃣ TYPE kiezen:
   [🔵 Professioneel] [🟣 Collectief] [🟢 Informeel]

2️⃣ WIE dropdown (passend bij type):
   - Professioneel: Ambulante GGZ, Budgetcoach, etc.
   - Collectief: Vrijwilligers, Buurtcentrum, etc.
   - Informeel: Partner, Familie, Vrienden, etc.

3️⃣ ROL dropdown:
   - Praktische hulp (administratie, boodschappen, ...)
   - Sociale steun (gezelschap, luisterend oor, ...)
   - Begeleiding (afspraken, budgetbeheer, ...)
   - Behandeling (gesprekken, medicatie, ...)
   - Anders (vrij tekstveld)
