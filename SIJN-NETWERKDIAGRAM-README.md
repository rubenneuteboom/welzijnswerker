## Beschrijving

Dit diagram toont de **basis van de SIJN-methodiek**: netwerkbeweging als een web van mogelijkheden, niet als een ladder.

## Layout

```
          GEMENGD       GEEN NETWERK
          
1-PERSOONS

          INFORMEEL     FORMEEL
```

## Netwerkposities

| Positie | Kleur | Hex | Betekenis |
|---------|-------|-----|-----------|
| GEMENGD | Oranje | #fed7aa | Spreiding informeel + formeel |
| GEEN NETWERK | Wit/grijs | #ffffff | Geen vaste steun |
| 1-PERSOONS | Geel | #fef3c7 | Steun via één persoon |
| INFORMEEL | Geel | #fef3c7 | Steun uit persoonlijke relaties |
| FORMEEL | Roze | #fce7f3 | Steun van professionals |

## Pijlenlogica

### Vanuit GEEN NETWERK (alleen uitgaand):
- → GEMENGD ✓
- → INFORMEEL ✓
- → FORMEEL ✓

**Filosofie:** Vanuit geen netwerk kun je bewust netwerk opbouwen in alle richtingen, maar je valt niet bewust terug naar isolement.

### Vanuit 1-PERSOONS (alleen uitgaand):
- → GEMENGD ✓
- → INFORMEEL ✓
- ✗ GEEN verbinding met FORMEEL
- ✗ GEEN verbinding met GEEN NETWERK

**Filosofie:** Vanuit een kwetsbaar 1-persoonsnetwerk kun je bewust verbreden naar gemengd of informeel, maar niet direct naar volledig formeel of volledig geen netwerk. Dit benadrukt de kwetsbaarheid van deze positie.

### Tweerichtingsverkeer:
- GEMENGD ↔ INFORMEEL ✓
- GEMENGD ↔ FORMEEL ✓
- INFORMEEL ↔ FORMEEL ✓

**Filosofie:** Beweging tussen deze posities is in beide richtingen mogelijk, afhankelijk van context en behoefte.

## Filosofie

Dit diagram is niet:
- ❌ Een ladder (links→rechts = slecht→goed)
- ❌ Een voorgeschreven route
- ❌ Een hiërarchie
- ❌ Een groeimodel

Dit diagram is wel:
- ✅ Een web van mogelijkheden
- ✅ Context-afhankelijk (wat past nu?)
- ✅ Niet-normatief (geen positie is "beter")
- ✅ De basis van SIJN-denken
